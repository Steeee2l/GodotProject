# 캐릭터 스프라이트 공식 호출명

Project Atlas의 캐릭터 메뉴와 동일한 이름 체계입니다. 이후 캐릭터 제작 요청에서는 아래 한글 이름이나 코드명을 사용합니다.

| 이름 | 코드명 | 현재 역할 | 연결된 주요 에셋 |
|---|---|---|---|
| 나비 (Nabi) | `CHAR_NABI` | 주인공·종로 정찰묘 | 기본 8방향, 이동, 근접 공격, 구르기, 휴식 |
| 서린 | `CHAR_SEORIN` | 동료·생존 전투묘 | 여성 동료 8방향 이동 세트 |
| 모카 | `CHAR_MOKA` | 구조 주민·겁먹은 상태 | 웅크린 구조 주민 |
| 도담 | `CHAR_DODAM` | 쉘터 주민·작업묘 | 장모 주민 이동·대기 세트와 생성 원본 |
| 장고 | `CHAR_JANGO` | 쉘터 주민·물물교환 상인 | 붉은 옷의 상인 캐릭터 |
| 루미 | `CHAR_LUMI` | NPC·유물 감정상 후보 | 회중시계를 든 삼색 고양이 |
| 탄이 | `CHAR_TANI` | NPC·시설 정비공 | 안전모와 공구 장비를 착용한 정비공 |
| 단풍 | `CHAR_DANPUNG` | NPC·붉은 작업복 주민 | 주황색 털의 쉘터 주민 후보 |
| 봉구 | `ENEMY_BONGGU` | 적·폐허 약탈자 | 육중한 누더기 전술복 약탈자 |
| 강철 | `ENEMY_GANGCHEOL` | 적·근접 중장병 | 근육질 스핑크스 전투원 |
| 핀 | `ENEMY_PIN` | 적·수류탄 투척병 | 투척물과 경량 전술 장비를 갖춘 적 |
| 포화 | `BOSS_POHWA` | 보스·로켓 중화기병 | 로켓 발사기 보스 8방향 세트 |
| 까마귀 | `ENEMY_RAIDER_MARKSMAN` | 적·권총 사수 | 초기 권총 약탈자 콘셉트 |
| 멧돌 | `ENEMY_RAIDER_BRUISER` | 적·근접 돌격수 | 초기 근접 약탈자 콘셉트 |
| 하나 | `CHAR_HANA_LEGACY` | 초기 생존자 시트 | 인간형 생존자 이동·사격 자료 |

이름은 스프라이트를 찾고 제작 지시를 연결하기 위한 기준명입니다. 서사상 이름이나 역할이 확정되면 이 문서와 Project Atlas의 이름을 함께 변경합니다.
