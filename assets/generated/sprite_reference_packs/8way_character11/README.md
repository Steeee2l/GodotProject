# Directional Sprite Reference Pack

These eight single-frame anchors come from the accepted `character-11` curation run.
They are used only for screen-axis, silhouette placement, ground-line, and three-quarter
direction guidance. The newly uploaded base image remains the identity/style source.

Naming is intentionally aligned with the sprite-gen direction taxonomy:

`down`, `down_right`, `right`, `up_right`, `up`, `up_left`, `left`, `down_left`.

The pipeline attaches the matching `*_idle.png` as an additional reference when a run
does not yet have an accepted idle anchor. For walk rows it also attaches the matching
`*_walk.png` strip for foot-phase and motion-rhythm guidance. These images must never
be used to copy another character's clothing, face, palette, or accessories.
