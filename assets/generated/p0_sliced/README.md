# P0 sliced source assets

The generated source sheets in the sibling p0_sources directory are split here
into 37 transparent PNG cells:

- combat_vfx: 9 effects
- mission_icons: 12 objective/status icons
- item_icons: 12 consumable/ammo/mod/scrap icons
- player_hit: 4 front-facing hit frames

These files are staging assets. They still need pixel-size normalization,
catalog registration, scene wiring, and sprite-gen/runtime QA before they are
considered shipped assets.
